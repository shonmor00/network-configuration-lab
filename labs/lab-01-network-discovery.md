Project Overview
This lab explores using basic network configuration using Windows Command Prompt. This objective was to identify the computer's network settings and understand how devices communicate over a network.  

Objectives
- IDENTIFY THE COMPUTER'S IPV4 ADDRESS
- LOCATE THE SUBNET MASK AND DEFAULT GATEWAY
- IDENTIFY CONFIGURED DNS SERVERS
- EXAMINE AVAILABLE NETWORK ADAPTER INFORMATION
- BECOME FAMILIAR WITH WINDOWS NETWORKING COMMANDS

TOOLS USED
- Operating System: Windows 10
- Network Connection: WiFi
- Command-Line Interface: Windows Command Prompt

Commands Executed
1. ipconfig
   -displayed basic IP configuration information for the computer's network adapters.
2. ipconfig /all
   -displayed detailed network configuration information, including IP addressing, subnet configuration, DNS servers, and physical adapter information.

Technical Concepts Learned
- IPv4 Address: Identifies a network interface for communication across IP networks.
- Subnet Mask: Helps determine which portion of an IP address identifies the network and which identifies the host.
- Default Gateway: Provides a route to destinations outside the local network.
- DNS: Resolves domain names into IP addresses.
- Network Adapter: Hardware or a virtual interface that connects a device to a network.
